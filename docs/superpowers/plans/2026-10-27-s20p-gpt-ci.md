# CLX-S20P reviewed build implementation plan

> Execute inline in this isolated fork checkout. The user's current request
> authorizes implementing and activating the previously discussed design.

**Goal:** Repair GPT writes and publish only checked, reviewed S20P FIP candidates.

**Architecture:** A small upstream C patch, a native C regression harness,
trusted source preparation and image verification scripts, and a daily Actions
pipeline with isolated build and release permissions.

**Tech Stack:** C, Python standard library, Bash, Docker, GitHub Actions, gh.

  function block, run it with synthetic primary images and independently parse
